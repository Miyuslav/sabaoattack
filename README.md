# 😾 サバオアタック

> — サバオッチ presents —

鯖男（キジトラ）となって、弟分の巻男（サングラス）を3つの部屋で倒す、ブラウザ動作のアクションRPGです。

---

## 🎮 遊び方

### 操作

| 操作 | PC | スマホ |
|------|-----|--------|
| 移動 | WASD / 矢印キー | 左下バーチャルパッド |
| 🐾 爪（近距離） | Z / クリック | 右下 🐾 ボタン |
| 🍣 寿司投げ（遠距離） | X / 右クリック | 右下 🍣 ボタン |

### ルール

- 巻男に近づかれると継続ダメージ
- 巻男は定期的に💩を投げてくる。当たるとHPが減る
- 部屋の全巻男を倒すと次の部屋へ進める
- HPが0になるとゲームオーバー

### 成長システム

- 巻男を倒すとEXPを獲得
- EXPが満タンになるとレベルアップ → HP・ATK上昇

## 🏠 ステージ構成

| ステージ | 場所 | 巻男の数 | 障害物 |
|----------|------|----------|--------|
| 1 | 🍳 台所 | 1体 | シンク台・冷蔵庫 |
| 2 | 🛋️ 北欧風居間 | 2体 | ソファ・テーブル |
| 3 | 🐾 猫のゲージ | 3体 | 💧 水皿 |

---

## 🔊 サウンド

全て Web Audio API で合成。外部ファイル不要。

- **BGM**: マイナー調バトルテーマ（スクエア波 + ノコギリ波 + ドラム）、ループ
- **効果音**: 爪、寿司投げ、ヒット、うんち着弾、敵撃破、ゲームオーバー
- **クリア音**: マリオ風クリアファンファーレ（3rd ステージクリア後）
- BGM と効果音は独立チャンネル。効果音再生時は BGM を自動ダッキング

## ⚙️ 技術仕様

| 項目 | 内容 |
|------|------|
| 動作環境 | モダンブラウザ（Chrome / Safari / Firefox） |

| 描画 | Canvas API（手描き） |
| サウンド | Web Audio API |
| スマホ対応 | タッチ操作・バーチャルパッド |
| ファイル構成 | HTML 1ファイル完結 |

### 速度定数（調整用）

```js
const PL_SPD      = 1.0;   // プレイヤー移動速度
const EN_BASE_SPD = 0.28;  // 敵の基本速度
const EN_SPD_INC  = 0.06;  // 敵速度の増加量（ステージごと）
const PROJ_SPD    = 4.0;   // 寿司弾の速度
const EPROJ_SPD   = 2.0;   // うんち弾の速度
```

## 🐱 キャラクター

### 😾 鯖男（プレイヤー）
キジトラ猫。凶暴。HP が低くなると目がつり上がる。

### 😎 巻男（敵）
鯖男より一回り大きいキジトラ猫。サングラス着用。近づいてくるほか、うんちを遠距離で投げてくる。HP が低くなると赤くなる。
